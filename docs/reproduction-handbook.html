HexMaze Sweep 复现手册

在 HexMaze 海马数据（rat6_491391 / 20260716）上检测 theta sweep、 并复现 Tang et al. 2026（Nat Neurosci）各项分析的完整方法与参数。交接给任何人后， 按第 7 节命令即可端到端重跑。

0一句话总结

该数据存在与 Tang 论文定量一致的 theta sweep（长度 21.6 vs 论文 22.0 ± 2.5 cm， 前向偏置），检出率较低源于细胞数与迷宫尺度（prevalence 0.167 vs 论文 ~0.45）。 没有论文的逐周期左右交替（556 个 triplet 下 51.1% vs null 52.3%）；相反，所有测过的轴都呈 模式驻留：前/后向 sweep 成片出现（切换率 31.7% 显著低于置换 37.7%，p=0.0005）， 且距 goal <60 cm 时 94% 的 sweep 翻转为后向（回顾模式）。 以上除 goal-sweep 特异性外，全部在第二个 session（20260717）复现——见 §12。

3预处理（hexmaze_sweeps/data.py）

  • 时间网格：bin_s = 0.01（10 ms），从 0 到 min(追踪结束, 最后一个 spike)。
  • 速度：逐 bin 位移 / bin_s，高斯平滑 speed_smooth_s = 1.0 s；无追踪处为 NaN。
  • moving direction = 行进方向（位置梯度的 arctan2，平滑 head_dir_smooth_s = 0.10 s）。 不用 DLC 头方向——该数据集 DLC 置信度列在写 NWB 时被丢弃，关键点会跳。

4Theta 相位与周期（decoding.py）

  • channel 23 @1500 Hz → Butterworth 2 阶 5–10 Hz filtfilt → Hilbert 相位 → unwrap 后插值到 10 ms bin 中心。
  • 相位零点重定在群体放电最低的相位（60 个相位 bin 求均值放电率取 argmin）。
  • 周期 = 重定零后相位的上穿零点；仅保留时长 80–220 ms（4.5–12.5 Hz）→ 本 session 30,126 个周期，其中跑动（>15 cm/s）8,617 个。

8衍生分析：方法与参数

8.1 相位进动（scripts/pooled_precession.py）—— sweep 存在性的独立证据

  • 细胞入选：跑动（≥15 cm/s）中场内 spike ≥100（不要按 bits/spike 选，偏爱稀疏细胞）。场峰取 2.5 cm bin、σ=2 bin 平滑 rate map 的 argmax；场窗 = 峰周 20 cm。
  • 圆-线性拟合：斜率格点 ±30°/cm × 241 点，最大化合成向量长 R；零假设 = 各细胞相位整体随机旋转 + 配对打乱，200 次。
  • 结果：41 细胞 / 10,303 spikes，斜率 −7.9°/cm，85% 细胞为负，R=0.221 ≫ shuffle 97.5 分位 0.069。

8.2 单细胞 GLM shift model（hexmaze_sweeps/glm_shift.py，Tang 方法三改）

  • 模型：逐细胞 y ~ Poiss(exp(β₀+βX))；协变量 = 位置（2D 高斯基，10 cm 三角网格，σ=5 cm（论文 2 cm，10 cm 网格下覆盖有空洞，故改；可 --pos-sigma-cm 2 复原），buffer 30 cm）+ moving direction 与 theta 相位（各 50 个 Von Mises 基，κ=10）；各组 PCA 保 99% 方差（2883→607、50→11、50→11）后 z-score；sklearn PoissonRegressor(alpha=1e-4, max_iter=500)；拟合速度门 ≥10、评估 ≥15 cm/s。
  • 读出：位置协变量沿 moving direction 平移 d ∈ [−30, +45] cm（步长 2.5），log-rate 以未平移最大值 + ln2 封顶；12 个相位 bin；逐 bin 位移后验均值按相位平均（总似然 argmax 会被 d=0 钉死，不灵敏）；null = 相位标签整体时间平移 ×200。
  • 结果：位移曲线峰-峰 4.8 cm（p=0.005，恒为正 +1.4→+6.2 cm；后验收缩使其为下界）。

8.3 Goal sweeps（scripts/goal_sweeps.py，对应 Tang Fig. 1f–l）

  • sweep 方位 = 动物位置 → 段内距动物最远点；goal 方位 = 动物 → goal(421)；对齐判据 |夹角| ≤ 10°。
  • 空间零假设：其余 95 个节点（距真 goal >60 cm）作 pseudo-goal，各自算对齐率（剔除动物距 pseudo <20 cm 的 sweep）。
  • 结果：15.4% 对齐 goal（论文 16.3±4.4%）；真 goal 位于 pseudo 分布 94 分位（边缘，p≈0.06）；对齐率随距离上升（>2.6 m 处 27%）。
  • 混淆声明：本 session 单 goal，无法做论文的三 goal 去混淆控制；heading 不朝 goal 时 goal 对齐（8.2%）≈ heading 对齐（10.3%），提示 goal 调谐大半由"朝 goal 跑 + 前向扫"承载。

8.4 前向/后向结构（scripts/forward_backward.py + plot_fb_visualization.py）

  • 分类：|sweep − heading| ≤60° = F；≥120° = B；其余侧向。结果 F 681 / B 560 / L 196。
  • 近 goal 回顾翻转：距 goal ≤60 cm 时 94% 为 B（n=48）；60–120 cm 56%；>90 cm/s 冲刺时 B 仅 30%。F/B 中位速度相同（51/49 cm/s）——B 不是低速噪声。
  • 模式驻留（非交替）：663 对相邻周期切换率 31.7%，episode 内置换 null 37.7%（2000 次），p(持续)=0.0005；严格 F-B-F 三连 12.8%（独立期望 ~25%）。

10注意事项（按踩坑顺序）

  1. NWB 内嵌 LFP 不可用（伪 5 Hz）。一切 theta 相关都必须走 --lfp-npy。备选 --theta pca（群体重建相位）质量较差，仅作 fallback。
  2. 解码饥饿是检出瓶颈：81%（严档）的跑动周期凑不齐连续有效 bin；形状门（直线度中位 0.96）几乎不拒绝。调灵敏度应调 shuffle 分位 / 最少 bin / 跳跃上限，而不是直线度。
  3. Tang 约定必须配 origin 门（§6 高亮行），否则长度被锚点漂移污染。
  4. 交替性结论对方向定义敏感：vollan 约定 149 个 triplet 上曾出现 58.4%"疑似交替"，在更准的 tang 方向 + 556 triplet 下消失。报告交替性一律用 tang 约定。
  5. 近 goal 后向翻转已跨 session 复现（day1 94%/n=48，day2 90%/n=109，见 §12）；reward 区 place field 密度对解码的潜在偏置仍值得在更多动物上排查。
  6. goal-sweep 特异性未跨 session 复现（day1 94 分位，day2 46 分位）——day1 的边缘结果按噪声 处理；本数据集（单 goal、走廊）目前不支持论文式 goal-sweep 结论。
  7. GLM 位置基 σ=5 cm 系有意偏离论文（2 cm）；严格复现加 --pos-sigma-cm 2。
  8. 脚本内数据路径为本机绝对路径；换机器/换 session 改各脚本头部常量即可，分析全部从 results/glm_shift/cache/ 的两个 npz 出发（解码 dump + session 缓存），不必重读 NWB。
